# Minimal pin set for the PyInstaller-bundled open-notebook sidecar.
#
# Goal: ship the smallest possible binary that still exposes the FastAPI
# endpoints QuantVault actually consumes (sources, search, per-source chat,
# transformations).  Heavy ML provider SDKs (anthropic, google-genai, groq,
# mistralai) are EXCLUDED — the embedded sidecar uses the local LM Studio /
# Ollama path through `langchain-openai` and `langchain-ollama` only.
#
# Versions chosen against open-notebook 1.8.5's pyproject.toml.  Pinned at
# tested baselines; PyInstaller's --collect-submodules + the hidden-imports
# list in scripts/build-onb-binary.mjs takes care of dynamic discovery.
#
# To use (Windows PowerShell):
#   python -m venv .venv-onb
#   .\.venv-onb\Scripts\Activate.ps1
#   python -m pip install --upgrade pip wheel
#   python -m pip install -r scripts/onb-minimal-requirements.txt
#   python -m pip install pyinstaller==6.20.0
#   npm run build:onb-binary
#
# After a successful run, the binary lands in
# src-tauri/resources/services/open-notebook/.
